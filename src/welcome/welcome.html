Welcome to Focus Guard.

Three quick steps close the gaps an extension can't close on its own. You can come back to this page any time from the popup's Setup checklist link.

1 Turn off Gemini in Chrome Done

Chrome's "Ask Gemini" button and side panel are part of Chrome itself, so no extension can block them. Turn them off in Chrome's settings:

  1. Open Chrome's menu (the three dots, top right) and go to Settings.
  2. Click AI innovations, then Gemini in Chrome. On some Chrome versions this section is called Google AI or AI Premium.
  3. Turn off every switch there, including Show Gemini at the top of the browser and Show Gemini in system tray and turn on keyboard shortcut. That removes the side panel, the keyboard shortcut and the "Ask Gemini" prompts.
  4. To remove the sparkle icon from the toolbar, right-click it and choose Unpin.

2 Allow Focus Guard in Incognito Done

Chrome doesn't run extensions in Incognito windows unless you allow it, so AI sites would be open there. On Focus Guard's settings page, turn on Allow in Incognito.

Focus Guard is allowed in Incognito windows, so AI sites are blocked there too.

In Incognito, Chrome shows its own error page instead of Focus Guard's, so you can't unlock a site there. Unlock it from a normal window instead, then type the site's address again in Incognito. Reloading Chrome's error page won't open it.

Changing this setting restarts Focus Guard, which may close this page. Reopen it from the popup's Setup checklist link.

3 Allow Chrome notifications in Windows

Focus Guard tells you when a pass is about to end, has ended or has moved to another site. Windows only shows these if Chrome is allowed to notify you:

  1. Open Windows Settings, then System, then Notifications.
  2. Make sure Google Chrome is turned on in the list of apps.
  3. Turn off Do not disturb, or Windows will hide notifications while it's on.

That's it. Click the Focus Guard icon in your toolbar to start your first coding session.
