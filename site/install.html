Install Focus Guard.

Focus Guard isn't in a browser store, so you install it from a zip file with Load unpacked. It takes about two minutes.

Download Focus Guard

This link always downloads the newest version. Websites can't open browser pages like chrome://extensions, so you'll type those addresses yourself.

Install guide

Pick the guide for your browser below.

Install in Google Chrome

  1. Download focus-guard.zip.
  2. Extract it into a folder you'll keep, like Documents\focus-guard. In Windows, right-click the zip, choose Extract All, and pick the folder. Chrome loads Focus Guard from this folder every time it starts, so deleting or moving the folder removes the extension.
  3. Open the extensions page: type chrome://extensions in the address bar and press Enter.
  4. Turn on Developer mode with the switch in the top-right corner.
  5. Click Load unpacked. The button appears once Developer mode is on.
  6. Select the folder you extracted, the one with manifest.json directly inside it, and click Select Folder.
  7. Pin it to the toolbar: click the puzzle-piece Extensions button next to the address bar, then the pin next to Focus Guard.

Install in Microsoft Edge

  1. Download focus-guard.zip.
  2. Extract it into a folder you'll keep, like Documents\focus-guard. In Windows, right-click the zip, choose Extract All, and pick the folder. Edge loads Focus Guard from this folder every time it starts, so deleting or moving the folder removes the extension.
  3. Open the extensions page: type edge://extensions in the address bar and press Enter.
  4. Turn on Developer mode with the switch in the left-hand panel.
  5. Click Load unpacked. The button appears once Developer mode is on.
  6. Select the folder you extracted, the one with manifest.json directly inside it, and click Select Folder.
  7. Show it in the toolbar: click the puzzle-piece Extensions button next to the address bar, then the eye icon (Show in toolbar) next to Focus Guard.

Seeing a warning about developer mode extensions? That's expected. Chrome and Edge may show a message, for example when the browser starts, about extensions running in developer mode, and offer to turn them off. It appears for every extension installed with Load unpacked, because it didn't come from a store.

Close the message and keep Focus Guard on. If you turn developer mode extensions off, Focus Guard stops working until you switch it back on at the extensions page.

After installing

Focus Guard opens a short setup checklist for your browser: turning off the browser's built-in AI, allowing Focus Guard in private windows, and allowing notifications. Then click the Focus Guard icon in the toolbar to start your first coding session.

Updating to a new version

Extensions installed with Load unpacked don't update by themselves. When there's a new version on the Releases page:

  1. Download the new focus-guard.zip.
  2. Replace the folder's contents: open the folder you installed Focus Guard from, delete everything inside it, and extract the new zip into that same folder. Deleting the old files first means nothing from the old version is left behind.
  3. Click reload: go to chrome://extensions or edge://extensions and click the circular reload arrow on the Focus Guard card.
  4. Check the version: the card should show the version number from the Releases page.

Keep the same folder. Your browser recognises Focus Guard by the folder it was loaded from. Updating in the same place keeps your blocklist, stats and settings. Loading the new version from a different folder installs it as a separate copy, starting from scratch.

Want to hear about new versions? On GitHub, click Watch, then Custom, and tick Releases.

Removing Focus Guard

On the extensions page, click Remove on the Focus Guard card, then delete the folder you installed it from. Removing it deletes everything Focus Guard saved.
